**Операция**: exportReport(format: ReportFormat)

**Ссылки:** Прецеденты: Вывод аналитики по мероприятию

**Предусловия:**
- Отчет по мероприятию сформирован.
- Выбран формат выгрузки отчета.

**Постусловия:**
- Экземпляр r класса AnalyticsReport сохранен в Pass Storage (сохранение объекта).
- Сформирован файл отчета в выбранном формате (создание объекта).
- Сформировано подтверждение успешной выгрузки отчета.
- Отчет доступен менеджеру для дальнейшего использования.
