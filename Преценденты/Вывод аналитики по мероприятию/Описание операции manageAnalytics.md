**Операция**: manageAnalytics()

**Ссылки:** Прецеденты: Вывод аналитики по мероприятию

**Предусловия:**
- Менеджер аутентифицирован в FTS.
- В Event Storage есть мероприятия, по которым в Pass Storage есть данные о продажах.

**Постусловия:**
- Создан экземпляр fts класса FTS (создание экземпляра).
- Из Event Storage получены сведения о мероприятиях с данными о продажах (чтение данных).
- Заполнено поле fts.eventsList данными о мероприятиях (модификация атрибута).
- FTS отобразила список мероприятий и кнопку «Показать аналитику».
