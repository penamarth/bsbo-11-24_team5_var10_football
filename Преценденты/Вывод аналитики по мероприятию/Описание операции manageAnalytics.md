Ссылки: Прецеденты: Вывод аналитики по мероприятию

Предусловия:
- Менеджер аутентифицирован в системе.
- В базе данных есть мероприятия с данными о продажах.

Постусловия:
- Создан экземпляр anl_ctrl класса AnalyticsController (создание экземпляра).
- Из базы данных получены сведения о мероприятиях с данными о продажах (чтение данных).
- Заполнено поле anl_ctrl.eventsList данными о мероприятиях (модификация атрибута).
- Система отобразила список мероприятий и кнопку «Показать аналитику».
