**Операция**: manageAnalytics()

**Ссылки:** Прецеденты: Вывод аналитики по мероприятию

**Предусловия:**
- Менеджер аутентифицирован в FTS.
- В EventRepository есть мероприятия, по которым в PassRepository есть данные о продажах.

**Постусловия:**
- Из EventRepository получены сведения о мероприятиях с данными о продажах (чтение данных).
- Вызван `PassRepository.getPassesWithFilter()` с проверкой `coversAnyMatch()` для каждого мероприятия (чтение данных).
- Список мероприятий с данными о продажах передан в FTS (передача данных).
- FTS отобразила список мероприятий.
