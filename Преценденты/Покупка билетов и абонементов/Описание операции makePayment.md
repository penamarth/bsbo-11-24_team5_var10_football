**Операция**: makePayment(amount: Money)

**Ссылки:** Прецеденты: Покупка билетов и абонементов

**Предусловия:**
- Покупка подтверждена, способ оплаты выбран.
- Адрес электронной почты покупателя введён.
- Бронь места ещё действует.

**Постусловия:**
- Создан экземпляр `payment` класса `Payment` (создание экземпляра).
- Атрибуту `payment.amount` присвоено значение `amount` (модификация атрибута).
- `payment` связан с `purchase` (формирование ассоциации).
- При оплате картой данные платежа переданы на удалённый сервер для списания средств через банковский API (передача данных).
- Создан экземпляр `ticket` класса `Ticket` — билет на матч или абонемент на сезон с уникальным QR/штрихкодом (создание экземпляра).
- `ticket` связан с `event` и `seat` (формирование ассоциации).
- Атрибуту `seat.status` присвоено значение «Занято» (модификация атрибута).
- Экземпляр `reservation` удалён (удаление экземпляра).
- Покупателю выданы сдача (при оплате наличными), билет/абонемент и чек.
- Данные `ticket` и адрес `purchase.email` переданы в систему почтовых уведомлений, на электронную почту покупателя отправлено письмо с электронной копией билета/абонемента (передача данных).
- Результат операции зафиксирован в журнале аудита.
